# Pi05 Policy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a schema 3 `pi05` policy for local LeRobot ACOne checkpoints, reusing Qwen35 chunk trimming and blending.

**Architecture:** Extract Qwen35's framework-free scheduling into SDK `AsyncChunkPolicy`, preserving Qwen behavior through a thin wrapper. Add an isolated LeRobot backend, explicit checkpoint/config validation and policy-owned Docker deployment. RC remains the only robot command publisher.

**Tech Stack:** SDK standard library/NumPy, isolated Python 3.12 and LeRobot 0.6.1, pinned compatible PyTorch/Transformers, Docker Compose schema 3.

**Spec:** `docs/superpowers/specs/2026-10-28-pi05-policy-design.md`

## Global Constraints

- User confirmed existing LeRobot-format ACOne fine-tuned weights and unknown training version; target stable v0.6.1 / `7e241bd630a3719a56157a497ce5d08f244784f1`.
- Every executable policy owns one container/host/process; no ROS/model dependencies in SDK, no external inference service.
- Reuse Qwen35 consumed-action alignment, full-overlap exponential blending and old grippers in overlap. Keep Qwen's `+0.15` correction in its wrapper only.
- Images copied before background inference; old epoch results cannot reach actions; model calls serialized and lifecycle bounded by existing supervisor.
- Local weights/tokenizer/processors only; strict loading must propagate failure rather than use PI05's catch-and-return-random override.
- Preserve unrelated dirty example-policy/docs/tests. No task commit/push unless requested; ignored `.codex/task-state.md` is the sole progress ledger.

## Review Focus

- Native safetensors with shared tensors: preserve tied weights and reject missing/unexpected/corrupt weights (Task 3).
- Saved relative-action processors: restore shared state link and prevent a second delta-to-absolute conversion (Task 3).
- Saved normalization state and renamed camera keys: require complete state/feature coverage, no silent missing-stat fallback (Tasks 2/3).
- Checkpoint horizons other than 50 and inference finishing across a pause: validate lengths/thresholds and discard old-epoch data (Tasks 1/2).
- No NVIDIA/checkpoint locally: report CPU/fixture/image evidence separately and provide target GPU probe without claiming hardware acceptance (Task 4).
